# ทะเบียนคุมงานจัดซื้อจัดจ้าง

โปรแกรมเว็บสำหรับบันทึก ค้นหา และติดตามสถานะใบสั่ง/สัญญา
ทำงานทั้งหมดในเบราว์เซอร์ (ไม่ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล) ข้อมูลถูกเก็บไว้ใน
`localStorage` ของเบราว์เซอร์แต่ละเครื่อง

## วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเข้าผ่านลิงก์ GitHub Pages
หลังติดตั้งตามขั้นตอนด้านล่าง

## วิธีติดตั้งบน GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub (เช่นชื่อ `procurement-register`)
2. อัปโหลดไฟล์ `index.html` นี้ขึ้นไปที่ repository (หน้าแรกของ repo หรือ
   ลาก-วางผ่านหน้าเว็บ GitHub ก็ได้ ไม่ต้องใช้คำสั่ง git)
3. ไปที่ **Settings → Pages**
4. ในหัวข้อ **Build and deployment** เลือก Source เป็น **Deploy from a branch**
5. เลือก branch เป็น `main` (หรือ `master`) และโฟลเดอร์เป็น `/ (root)` แล้วกด **Save**
6. รอประมาณ 1-2 นาที จะมีลิงก์ปรากฏที่ด้านบนของหน้า Pages รูปแบบ
   `https://<username>.github.io/<repo-name>/`
7. เปิดลิงก์นั้นเพื่อใช้งานโปรแกรมได้ทันที

## ข้อควรทราบ
- ข้อมูลที่กรอกจะถูกเก็บไว้ใน localStorage ของ **เบราว์เซอร์และเครื่องที่ใช้งาน
  เท่านั้น** ถ้าเปิดจากเครื่อง/เบราว์เซอร์อื่น หรือใช้โหมดไม่บันทึกประวัติ
  (Incognito) จะไม่เห็นข้อมูลเดียวกัน
- หากต้องการให้ทุกคนในทีมเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ จะต้องเพิ่ม
  ฐานข้อมูล/เซิร์ฟเวอร์ส่วนกลาง (เช่น Firebase, Supabase) ซึ่งไม่รวมอยู่ในไฟล์นี้
- กดปุ่ม "ส่งออก CSV" ในโปรแกรมเพื่อสำรองข้อมูลออกมาเป็นไฟล์ได้ตลอดเวลา
